# Code of conduct

Be kind and assume good faith. Critique code and ideas, not people.

Harassment, personal attacks, and discriminatory language aren't welcome here, in issues, PRs, or anywhere else the project lives. Neither is publishing someone's private information.

If something happens that makes you uncomfortable, open a private security advisory on the repo or contact the maintainer through their GitHub profile. Reports are handled privately, and the maintainer can remove content or block participants who don't follow this.

This is adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/).
